# 脱外套动作：本地通用 VLM 对照测试

> 跨电脑安装以 [README.md](README.md) 为准。以下实验报告来自原开发电脑；`outputs/`、测试视频、模型缓存和本地标注不随 GitHub 上传，相关路径仅供本地复现实验时使用。

已补测 [Qwen3-VL-4B-Instruct 官方模型](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct)。当前结论是：它能在部分目标裁剪输入中描述衣物移除，但对原始拥挤画面、外套与包的区分及衣着变化前后的叙述不可靠，尚未通过完整动作理解验收。

## 方法

- 模型 revision：`ebb281ec70b05090aa6165b016eac8ec08e71b17`；本地 BF16、SDPA、确定性生成。没有上传视频到外部推理服务。
- 同一视频三个预先指定的诊断区间：A 约 0.2–8 秒普通行走；B 10–20 秒可见脱外套；C 20–27 秒脱完后行走。每秒约取两帧，保存精确源帧编号及时间。
- 每段是新对话，不传入前一段答案；提示要求描述动作与衣物变化，不告诉模型哪段发生了脱外套。用例文件内的预期结果只用于事后复核，不进入模型输入。
- 有参考图时，参考图来自片段开始前/当时已经确认的目标框。目标裁剪使用当前或过去的跟踪框并留周边空间，过期/缺失框使用空白图，不用未来帧插值。
- 这是“已经定位目标后的片段动作理解”诊断，不是语言选人验收。答案在输入片段末帧之后才能得到，不能拿回顾性动作描述冒充实时事件检测。

## 保留全部尝试结果

| 输入/提示 | B：真实脱外套片段的结果 | A、C：无新增脱外套动作 |
| --- | --- | --- |
| 全画面＋参考图，初版 JSON 提示 | 返回空动作列表；将 appearance 字段理解为时间，未识别动作 | 同样返回空动作，不能据此认定完整理解正确 |
| 全画面＋参考图，自由描述 | 错误地说衣着和携带物没有变化 | 未描述新的脱衣动作，但物品描述有错误 |
| 跟踪目标裁剪＋参考图，自由描述 | 提到移除衣物，但说拿下的是肩上的深色衣物，并错误地说拼色背心仍穿着 | 未描述新的脱衣动作，包/携带物描述仍有误 |
| 跟踪目标裁剪、无静态参考图，自由描述 | 描述移除外套、露出内搭；初始衣物被说成背心，深色包/外套仍混淆 | 未描述新的脱衣动作，但仍有物品细节错误 |

最后一组比全画面结果更接近实际，但说出“移除外套”几个词并不够。至少应同时正确说明哪件衣服被脱下、内搭保留、行为前后是同一条目标轨迹，并对遮挡中的未知行为保留不确定性。当前结果不满足全部条件，因此没有将模型文字直接用于身份记忆更新。

这些是同一开发视频上的诊断和提示迭代，不能当作独立测试集成绩。没有“穿脱/整理衣服/搬动包/只举手”等独立负样本，也没有经过人工复核的精确动作起止标注；不报告动作准确率或精确时间误差。

## 原始输出

- 初版 JSON 全画面（本地文件：`outputs/dataset1_actions_qwen3vl4b/report.json`）
- 自由描述全画面（本地文件：`outputs/dataset1_actions_open_full/report.json`）
- 目标裁剪加参考图（本地文件：`outputs/dataset1_actions_open_target/report.json`）
- 目标裁剪、只输入视频（本地文件：`outputs/dataset1_actions_video_only/report.json`）
- B 片段抽帧检查图（本地文件：`outputs/dataset1_actions_inputs/clip_B_frames.jpg`）

开放描述版本每段推理约 5.9–6.9 秒（不含模型加载、视频采集等待和跟踪）。峰值张量显存约 9.75–11.13 GiB，实测设备为 RTX 5070 Ti；VLM 与 SAM3 分别运行，这些数字不代表 12GB 的 4080 Laptop 可以同时常驻两者。

## 后续验收重点

先把测试集扩大到独立人物和视频，加入只挪动包、整理衣服、穿回外套、遮挡后换装等对照。冻结提示与输入采样后，比较更强的 VLM/显存适配方案，分别判断动作类别、衣物归属、前后外观及不确定性。只有这部分可靠后，再验证低频动作事件与轨迹/ReID 记忆联合工作；动作语义本身无法证明一个完全消失后重新出现的人仍是原目标。
